# Setup

Notes for keeping this profile working. GitHub only renders `README.md` on the profile — this file is just for you.

## Turn the snake on

The snake images 404 until the workflow has run once.

1. Repo → **Settings** → **Actions** → **General** → Workflow permissions → **Read and write permissions** → Save
2. Repo → **Actions** tab → **Generate snake animation** → **Run workflow**
3. Wait about a minute. It creates an `output` branch holding `snake.svg` and `snake-dark.svg`, then reruns itself every 12 hours.

## The terminal section (heatmap, portrait, info card)

All three are plain SVGs in `assets/`, generated by the Python scripts in `scripts/`. No third-party image services.

**The heatmap updates itself.** `.github/workflows/heatmap.yml` scrapes the public contribution calendar every day at ~06:17 UTC, redraws `assets/contrib-heatmap.svg` and commits it. It needs no token, just the same **Read and write permissions** setting as the snake. To run it by hand: **Actions** → **Refresh contribution heatmap** → **Run workflow**.

**The portrait and info card only change when you regenerate them** on your own machine:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r scripts/requirements.txt -r scripts/requirements-portrait.txt
python scripts/prep_photo.py path/to/photo.jpg   # crop to the head, cut the background, boost contrast
python scripts/make_ascii_svg.py                 # -> assets/topper-ascii.svg
python scripts/make_info_card.py                 # -> assets/info-card.svg (run it after the portrait: it copies its height)
```

The prepped photo is saved in `.portrait/`, which git ignores. Only the finished SVG gets committed, never the photo.

## Things you may want to change

| What | Where |
|---|---|
| Skill percentages | `assets/skills.svg` — each bar has an `animate` tag; the `to=` value is `percent × 5` (70% → 350) |
| Accent colour | Search `4ec9b0` in `README.md` and `assets/skills.svg` |
| Project sections | Each one is a `<details>` block in `README.md` |
| Info card lines | `ROWS` at the top of `scripts/make_info_card.py`, then rerun it |
| Portrait detail, glitch timing | `COLS`, `SUBJECT_FLOOR` and `GLITCH_EVERY` in `scripts/make_ascii_svg.py` |
| Background cut keeps the wall or loses hair | `prep_photo.py --rembg` (needs `rembg`, downloads a ~170 MB model once) |
| Heatmap colours | `PALETTE` in `scripts/render_heatmap_svg.py` |

The repo name must stay `TopperRN` — that is the account login GitHub matches against for profile repos.
